# Photo & figure placeholders

This folder intentionally contains no personal images. Add `profile.jpg` when ready, then follow the instructions in the root `README.md` to replace the profile placeholder. For project photos, diagrams and conference images, use descriptive filenames (e.g., `biodenim-lca-chart.png`, `saint-gobain-team.jpg`) and add them to the related cards only when approved for public display.

Do not add unpublished manuscripts, confidential industrial process visuals, personal documents, or third-party images without permission.
